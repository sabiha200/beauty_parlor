# PlushDiva Academy 💄

An online makeup education platform where students can browse courses, learn from certified instructors, and grow from beginner to professional makeup artist — plus a beauty parlor booking side with special offers and a work gallery.

**Live Demo:** [beauty-parlor-five.vercel.app](https://beauty-parlor-five.vercel.app/)

---

## 📋 Overview

This project is a makeup academy & beauty parlor website featuring:

- **Hero Section** – "Master the Art of Professional Makeup", trusted by 50,000+ students, with Start Learning / Watch Demo CTAs
- **Stats Bar** – 500+ video tutorials, 50+ expert instructors, 24/7 support
- **Browse by Category** – Eye Makeup, Lip Artistry, Skin Prep, Color Theory, Bridal Makeup, Special Effects, Nail Art, Hair Styling (each with course counts)
- **Featured Tutorials** – Popular courses with instructor name, duration, enrolled count, rating, and price/free tag
- **Why Choose Us** – HD video lessons, certified courses, self-paced learning, 24/7 support
- **Special Deals** – Time-limited offers (New Client Special, Bridal Package Deal, Spa Day Special)
- **Work Gallery** – Parlour interior, spa treatments, manicure, bridal makeup, products, salon, treatment rooms, consultations
- **Success Stories** – Graduate testimonials with career outcomes and ratings
- **Navigation Pages** – About, Courses/Services, Contact, Sign In/Register
- **Footer** – Quick links, resources, social media, and legal pages

## 🚀 Getting Started

### Prerequisites

Just a modern web browser — no build tools or dependencies required (unless the project uses a framework/build step; check for a `package.json` in the repo).

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/nadia-momo/<repo-name>.git
   ```
2. Navigate to the project folder
   ```bash
   cd <repo-name>
   ```
3. If it's plain HTML/CSS/JS, open `index.html` directly in your browser or use a live server extension.
   If it uses a framework, install dependencies and run the dev server:
   ```bash
   npm install
   npm run dev
   ```
